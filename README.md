The last text a dying phone sends at one percent battery: it rates its owner one star. The program writes the text to `entry.txt`.

> I rated you one star: 'Never charges on time. Screen always cracked. Would not recommend.' Goodbye.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
